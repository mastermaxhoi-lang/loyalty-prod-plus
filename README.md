# Прототип: Лояльность для бизнеса, прод и доработки

Кликабельный прототип четырёх страниц: Главная, витрина партнёров, Альфа-Пятница, страница оффера. Основа повторяет боевые страницы, поверх включаются доработки, каждая своим переключателем в панели «Прототип» внизу слева. Прототип, не сайт банка: формы ничего не отправляют, числа демонстрационные.

Открыть: https://mastermaxhoi-lang.github.io/loyalty-prod-plus/

Собирается из рабочей папки скриптом `_build/опубликовать.sh`, руками здесь не править.
